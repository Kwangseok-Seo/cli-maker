# 생성된 CLI 는 얇은 공개 façade 를 부르고, 명령 표면은 펼쳐서 낸다

`generate` 는 매니페스트를 독립 모듈(`main.go` + `go.mod`)로 뱉고 그 코드가 `internal/` 대신 얇은 공개 패키지 `clirun` 을 부르게 한다 — 생성물이 자기 `go.mod` 를 가진 남의 모듈이 되는 순간 Go 의 internal 규칙이 `internal/executor` 를 막기 때문이며(실측: `use of internal package … not allowed`, `replace` 로 소스를 쥐어 줘도 동일), 전부 공개하는 대신 좁은 창구만 내어 `clirun` 의 표면(타입 별칭 `Manifest`/`Command`/`Param`/`Auth` + 상수 `TimeoutFlag`/`OutputFlag` + `Run`)이 외부 계약으로 굳는 비용을 감수한다. 이것은 [ADR-0001](0001-runtime-interpreter-architecture.md) 의 번복이 아니라 그 ADR 이 *"뒤에 `generate` 서브커맨드로 얹을 수 있다"* 며 남긴 경로를 여는 것이고, 그 근거는 실현됐다 — 매니페스트 struct 가 그대로 템플릿의 입력이 됐고 `executor` 는 한 줄도 고치지 않았다. 타입을 별칭(`type X = Y`)으로 내보내는 것이 이 구조를 성립시킨다: 정의(`type X Y`)면 생성 코드가 만든 값이 `executor.Execute` 에 들어가지 못한다.

**명령 표면은 생성 코드가 직접 만든다** — 명령마다 익명 블록 하나에 `cobra.Command` 와 flag 등록을 펼쳐 놓고, 실행만 `clirun.Run` 에 위임한다. 익명 블록인 이유는 명령별 변수명을 만들지 않기 위해서다: 유저가 적은 이름(`repo-name`, `2fa`)이 Go 식별자 자리에 가면 깨지므로, **모든 유저 문자열이 문자열 리터럴 자리에만 놓이도록** 구조로 보장하고 거기에 `printf "%q"` 를 예외 없이 건다(날것으로 흘리면 `C:\temp` 가 컴파일은 통과하면서 값만 탭으로 바뀐다). 그 대가는 `internal/cli.Build` 와 `main.go.tmpl` 이 같은 표면을 두 번 진술하는 중복인데, `TestSurfaceMatchesRuntime` 이 생성 소스를 `go/parser` 로 읽어 런타임 cobra 트리와 대조해 **양방향으로** 봉인한다(둘 중 어느 쪽을 고쳐도 깨지는 것을 돌연변이 4건으로 확인). 생성 텍스트는 `format.Source` 를 통과한 뒤에야 나가고, 실패하면 한 바이트도 쓰지 않는다 — 리다이렉트된 파일이 반쯤 깨진 채 남는 것이 가장 조용한 실패이기 때문이다. `--dir` 은 우리 표식(`generate.GeneratedHeader`)이 없는 `main.go` 를 덮지 않고, `tidy` 가 손댄 `go.mod` 는 유지한다.

거부한 대안: **데이터만 생성**(매니페스트 리터럴 + `clirun.Root(m)`)은 중복이 0 이지만 golden test 가 자명해져 무의미해지고, ADR-0001 이 코드 생성을 열 이유로 든 "명령별 커스텀 로직"의 씨앗이 안 생긴다. **자립 생성**(executor 로직까지 복제)은 cli-maker 없이 빌드되지만 실행기 버그 수정이 전파되지 않고(측정: 재생성 없이 재빌드했을 때 A 는 반영, B 는 옛 복사본), 우리 Go 코드가 템플릿 문자열 안으로 들어가 `gofmt`·`go vet`·테스트의 사각지대가 된다. **모듈 안 생성**(repo 안의 `.go` 파일)은 internal 벽을 아예 피하지만 산출물이 `cli-maker` 하나로 남아 코드 생성의 핵심 값인 독립 배포 바이너리를 못 얻는다. 세 경로를 실제로 빌드한 대조표와 크기는 [M9 로그](../learn/milestones/M9.md). 생성되는 `go.mod` 에 `require` 를 적지 않는 것도 결정이다 — 실제 import 를 보고 채우는 것은 `go mod tidy` 가 더 정확하고, cli-maker 자신은 아직 배포 전이라 어떤 버전을 적어도 거짓이 된다. 다만 `go` 줄은 `generate.goVersion` 상수로 눈에 보이게 두고 1.22 하한을 테스트로 지킨다: 이 값이 내려가면 for 루프 변수의 의미가 바뀌어 생성물이 조용히 달라진다.
