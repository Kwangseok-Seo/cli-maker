# M3 — 매니페스트 → 명령 동적 생성

> 커밋: `4ae0cd4 feat: generate commands from manifests at runtime (M3)` · 로드맵: M3

## 한 일

매니페스트가 드디어 **CLI 표면**이 됐다. `internal/cli` 패키지의 `Build(m *manifest.Manifest) *cobra.Command` 가 매니페스트 하나를 그룹 명령으로 바꾸고, 그 아래 `m.Commands` 개수만큼 자식 명령을 루프로 만든다 — 각 자식의 `Run` 은 자기 `Command` 를 붙잡은 클로저다. `main.go` 는 `os.ReadDir("apis")` 로 매니페스트를 스캔해 `Build` 결과를 루트에 매단다. 설계 갈림길(명령 트리 형태·발견 방식)은 먼저 확정해 [ADR-0003](../../adr/0003-dynamic-command-surface.md) 로 박제했다. 실제 HTTP 호출은 M4 이므로 지금 `Run` 은 보낼 요청을 출력한다. **M3 완료.**

```
$ cli-maker petstore getPetById
GET https://petstore3.swagger.io/api/v3/pet/{petId}
```

`apis/` 에 `github.yaml` 을 떨어뜨리자 **재컴파일 없이** `cli-maker github listRepos` 가 생겼다 — [ADR-0001](../../adr/0001-runtime-interpreter-architecture.md) 의 약속이 처음 실물로 증명된 지점.

## 대표 함정

- [[composite-literals]]: `&cobra.Command{` 안에 `for` 루프를 넣어 `expected expression`. 리터럴(표현식)과 블록(문장)의 구별.
- [[closures]]: "`append` 가 값을 저장했겠지"라는 오해. 클로저는 **칸**을 붙잡고, 칸이 몇 개냐는 `go.mod` 의 언어 버전이 정한다(1.22 per-iteration). 같은 소스를 `go 1.21`/`go 1.26` 로 돌려 출력이 갈리는 것을 실측했다.
- [[error-handling]]: `apis/` 없음 분기에서 `rootCmd.Execute()` 를 부르고 `return` 을 빼먹어 **명령이 두 번 실행**됐다(`안녕, 철수!` 2회). 해소는 분기를 없애는 쪽 — `range nil` 은 0회 돈다.
- [[error-handling]]: 건너뛰기 경고에 파일·원인·개행이 다 빠져 `apis:` 만 찍혔다. 건너뛰기 정책의 생명은 경고 변별력.

## 결정

- [ADR-0003](../../adr/0003-dynamic-command-surface.md) — 매니페스트 하나 = `<api> <command>` 2단 그룹, `apis/` 스캔으로 발견.
- **에러 정책**: 매니페스트 하나가 깨지면 stderr 경고 + 그 파일만 건너뛴다(격벽). 세 정책(건너뛰기 / fail fast / 깨진 것도 노출)을 깨진 YAML 로 실물 비교한 뒤 골랐다. 3번 정책은 파싱 전이라 이름을 파일명에서 유추해야 하고, 데모에서 실제 `name: weather` 를 `broken` 으로 잘못 광고했다 — 그래서 탈락. 되돌리기 쉬운 국소 결정이라 ADR 은 아니다.
- **ADR-0002 근거 실현**: cobra 가 자식 명령을 알파벳순으로 자동 정렬해 "유저가 적은 순서 보존"이라는 ADR-0002 의 근거가 미실현 상태였다. `cobra.EnableCommandSorting = false` 로 등록 순서를 지켰다(패키지 전역이라 root 목록도 등록 순).

## 남긴 후속 과제

- 매니페스트에 `description`/`summary` 필드 — 지금 `Short` 는 `"%s API"` 파생 문자열이다.
- 매니페스트 이름 예약 — `help`·`completion` 은 cobra 가 자동으로 만드는 명령이라 충돌 가능(ADR-0003). **실측**: `name: help` 매니페스트를 넣으면 cobra 는 막지 않고 `--help` 에 `help` 가 **두 줄로 등재**되며(`help API` + `Help about any command`), `cli-maker help ping` 은 우리 그룹이 이겨 `GET https://example.com/ping` 을 냈다 — 즉 조용한 중복 + 등록 순서 의존. 로드 시점에 예약 이름을 거부해야 한다.
- 의미 검증(명령 단위) — 문법 오류는 파일 단위로 전부 잃지만, `method` 누락·`in:` 오타 같은 의미 오류는 명령 하나만 버릴 수 있다.
- `apis/` 발견 경로 — 지금은 cwd 기준. 설치된 바이너리용 경로·우선순위는 M5.
- `main.go` 가 76줄로 늘었다. 스캔 루프를 `internal/cli` 로 옮길지는 M4 의 코드 모양을 보고.
