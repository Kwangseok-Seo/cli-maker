# M2 — 매니페스트 파싱 (YAML → struct)

> 커밋: `32a1309 feat: parse manifest into structs (M2)` · 로드맵: M2

## 한 일

`apis/example.yaml` 매니페스트를 런타임에 읽어 Go struct 로 파싱하는 파이프라인을 세웠다. 먼저 grilling 으로 스키마 형태(**컬렉션 = name 필드를 가진 순서 있는 리스트**, map 아님)를 CONTEXT.md 와 대조해 확정하고 [ADR-0002](../../adr/0002-manifest-collections-as-ordered-lists.md) 로 박제. `internal/manifest` 패키지에 `Manifest`/`Command`/`Param`/`Auth` struct 를 태그로 정의하고, `Load(path)` 가 `os.ReadFile` → `yaml.Unmarshal(&m)` 으로 `*Manifest` 를 돌려준다. `parse <파일>` 하위 명령으로 배선하고 에러는 stderr 로 냈다. `parse apis/example.yaml` 이 slice·중첩·zero value 가 전부 채워진 덤프를 낸다. **M2 완료.**

## 대표 함정

- [[struct-tags]]: `baseUrl`(camelCase)은 태그 없이는 `BaseURL` 필드와 안 맞는다 → 태그 필수.
- [[serialization]]: ReadFile 에러 검사를 Unmarshal 뒤로 미뤄 "운으로" 동작(`:=` shadowing + `Unmarshal(nil)` 무해) → fail-fast 로 교정.
- [[errors-compile-vs-runtime]]: `Menifest` 오타를 `go build` 가 못 잡음 — 자기참조 일관 + 미사용 타입은 컴파일러 사각지대.
