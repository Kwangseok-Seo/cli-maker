# M7 — 출력 포맷

> 커밋: `d7d8ab1 feat: format output by destination (M7)` · 로드맵: M7 · 선행: [[M6]]

## 한 일

응답 본문이 M4 이래 `io.Copy` 로 그대로 흘러나가던 자리에 **포맷 층**을 끼웠다. `--output`(`-o`)으로 `raw|pretty|compact` 를 고르고, 안 주면 **stdout 이 터미널인지 보고 대신 정한다**. **M7 완료.**

새 패키지 `internal/format` 은 `Formatter` 인터페이스 하나와 구현 셋을 담는다. 포맷을 **고르는 곳**(플래그를 읽는 `internal/cli`)과 **쓰는 곳**(응답이 도착하는 `internal/executor`)이 떨어져 있어서, `executor` 는 이제 `io.Copy` 도 `"pretty"` 라는 문자열도 모른다.

## 측정 — 무엇을 만들지가 측정으로 정해졌다

로드맵엔 `--json`/`--compact` 라고 적혀 있었지만, 응답은 이미 JSON 이라 `--json` 의 의미가 불명했다. 표적을 셋 재 보고 나서야 표면이 정해졌다.

| 표적 | raw | pretty | compact |
|---|---:|---:|---:|
| `gh repo` (GitHub) | 5125 B, 1줄 | 5695 B | **5125 B — raw 와 동일** |
| `jsonplaceholder/todos/1` | 84 B, **6줄** | 84 B | **66 B** |
| `api.github.com/zen` | 16 B 평문 | ❌ `invalid character 'E'` | ❌ 같은 에러 |

- GitHub 은 **이미 compact** 라 `--compact` 가 그쪽엔 아무 일도 안 한다. pretty 로 주는 API 에서만 일한다 → **두 방향 다 필요**.
- 응답이 **JSON 이 아닐 수 있다**. `/zen` 은 평문 한 줄을 주는 정상 엔드포인트다.
- 실패해도 대상 버퍼는 **0 바이트**다(`{"ok":1} <html>…` 처럼 앞이 유효해도). → raw 폴백이 이중 출력 없이 안전.

`encoding/json` 의 **층 선택**도 측정으로 갈렸다. `map[string]any` 를 경유하면 키가 알파벳순으로 재배열된다(`id, node_id, name…` → `allow_forking, archive_url…`) — map 에 순서가 없고 `Marshal` 이 키를 정렬하기 때문. [[encoding-json]] 의 바이트→바이트 층만 쓴다.

## 실측 — 같은 명령, 네 가지 출력

```
$ cli-maker gh repo --owner spf13 --repo cobra      # 파이프/리다이렉트 → raw
{"id":12574344,"node_id":"MDEwOlJlcG9zaXRvcnkxMjU3NDM0NA==","name":"cobra", …

$ go run . gh repo --owner spf13 --repo cobra       # 터미널 → pretty (자동)
{
  "id": 12574344,
  "node_id": "MDEwOlJlcG9zaXRvcnkxMjU3NDM0NA==",
  "name": "cobra",                                  ← 서버가 보낸 필드 순서 그대로
```

비-JSON 응답 — `gh zen` 을 매니페스트에 폴백 표적으로 추가했다.

| 호출 | stdout | stderr | exit |
|---|---|---|---|
| `gh zen` (auto, 파이프) | `Design for failure.` | — | 0 |
| `gh zen -o raw` | `Approachable is better than simple.` | — | 0 |
| `gh zen -o pretty` | 〃 | `warning: response is not JSON — printing raw` | 0 |
| `gh zen -o compact` | 〃 | 〃 | 0 |

**stdout 은 네 경우 모두 원본 그대로**고, 경고는 명시했을 때만 stderr 로 간다.

```
$ cli-maker gh repo -o bogus …
Error: --output "bogus" 는 지원하지 않는다 (auto|raw|pretty|compact)   exit=1, stdout 0 B — 요청 자체를 안 보낸다
```

## 대표 함정

- **`byte` 를 변수 이름으로 썼는데 빌드도 `go vet` 도 통과했다.** `byte` 는 예약어가 아니라 미리 선언된 이름이라 가려도 에러가 아니다. 대가는 그 스코프에서 `[]byte` 를 쓰려는 순간 `byte (local variable) is not a type` 으로 온다 — **선언 지점이 아니라 사용 지점에서**. 같은 실수가 `isTerminal := isTerminal(...)` 로 한 번 더 났다([[identifier-shadowing]]).
- **stdout 이 터미널인지 세션 안에서 잴 수 없었다.** Bash 는 파이프(`prw-`), `!` 실행은 파일(`-rw-`) — 둘 다 콘솔이 아니다. 사용자가 별도 터미널 창에서 돌려야 `Dcrw-` 가 나왔다. 첫 측정을 콘솔 결과로 착각할 뻔했고, mode 문자열이 그걸 막았다. **값이 예상과 다르면 대상보다 측정 장치를 먼저 의심한다.**
- **M4 의 스트리밍이 여기서 끝난다.** `json.Indent` 는 `[]byte` 를 받으므로 전체를 `io.ReadAll` 해야 한다. 그래서 `Formatter` 를 `[]byte` 가 아니라 `io.Reader` 로 받게 해서 **raw 만은 `io.Copy` 스트리밍을 유지**했다 — 비용을 필요한 구현만 낸다.
- **`Warn` 필드에서 막혔다.** 원인은 문법이 아니라 "값이 설정을 들고 다닌다"가 낯설어서. 설명을 더 하는 대신 `Pretty{}` 와 `Pretty{Warn: os.Stderr}` 를 같은 응답에 돌려 보이자 풀렸다.
- **예약어 검사가 저절로 따라왔다 (실측).** `--output` 을 persistent flag 로 추가하자 `param "output" 는 예약된 flag 이름이다` 가 코드 수정 없이 나왔다 — M6 이 예약어를 상수로 적지 않고 `root.PersistentFlags().Lookup()` 으로 물어보게 한 덕. 상수 목록이었다면 이번에 갱신을 잊었을 자리다.

## 결정

- [ADR-0008](../../adr/0008-output-format-defaults-to-tty.md) — **기본값은 stdout 이 터미널인지로 정한다.** 비-JSON 폴백(경고만, exit 0)과 바이트→바이트 층만 쓰는 것이 그 결정을 성립시키는 조건이라 같은 ADR 에 묶었다. 거부한 대안: 항상 raw / 항상 pretty / `--pretty`·`--compact` bool 두 개.
- **개행은 포맷에 성공한 경로에서만 붙인다.** raw 와 폴백은 "바이트 그대로"가 계약이라 안 건드린다. M4·M5 가 남긴 "응답 개행" 과제가 이걸로 절반 닫혔다 — 터미널에서 `}` 에 프롬프트가 붙던 건 pretty 기본값이라 사라지고, `-o raw` 는 여전히 개행이 없다(의도).
- **경고는 유저가 `-o` 로 명시했을 때만.** auto 가 고른 pretty 가 실패한 것은 유저가 요청한 적 없는 일이다. 국소·가역이라 ADR 아님.

## 남긴 후속 과제

- **shorthand 는 `Lookup` 이 안 본다 (실측).** param 이름 `o` 는 `--o` 로 등록되고 `-o`(`--output`)와 공존한다 — 지금은 충돌하지 않지만, 매니페스트가 shorthand 를 정하게 되면 `ShorthandLookup` 검사가 필요하다.
- **포맷은 stdout 만 탄다.** M5 의 토큰 경고, M6 의 생략 보고 등 stderr 진단은 포맷 대상이 아니다. 지금은 맞지만 `--quiet` 류가 생기면 함께 다뤄야 한다.
- **`Formatter` 는 응답 전체를 하나의 값으로 본다.** NDJSON(줄마다 JSON)이나 스트리밍 API 는 `json.Decoder` 층이 필요하다 — 그때 `io.Reader` 시그니처가 값을 한다.
- **테스트가 없다.** `Formatter` 는 `io.Writer` 를 받으므로 `bytes.Buffer` 로 출력을 붙잡기 좋고, `isTerminal` 은 buffer 를 넘기면 자연히 false 다 — M8 의 첫 대상.
- **M4 잔여**: `--help` 에 필수 param 표시.
